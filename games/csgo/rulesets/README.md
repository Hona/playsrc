# Legacy Source 1 CS:GO Rulesets

## Objective

Own mode-specific rules layered over legacy Source 1 CS:GO behavior.

Legacy CS:GO surf, bhop, KZ, competitive, and standard-mode targets will be defined here by the game roadmap. They remain separate from identically named CS:S rulesets.

Rulesets consume legacy CS:GO mechanics and do not reimplement generic Source or game-wide behavior.
