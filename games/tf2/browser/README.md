# TF2 Browser Adapter

The adapter owns the browser worker boundary for the game-owned TF2 WASM module. One worker verifies at most 64 MiB of transferred WASM bytes, compiles one transferred BSP/configuration pair, stages canonical map plus PTF2 v5 presentation bytes, configures the map-bound course, advances bounded fixed ticks, executes complete Particle, Visibility, and StudioModel pose phases, and transfers each bounded result once. The client permits at most 64 pending requests. The application owns immutable-object fetching, pacing, physical input bindings, routing, IndexedDB lifetime, and worker termination.

The command carries forward/side/up movement, yaw/pitch, jump/crouch/speed, fire/detonate/reload/reset/respawn, class/team/weapon/mode requests, and one explicit map-entity activation identity. PSSN v4 carries the complete 96-byte Movement state plus final-tick wish, hull, step, trace-count, contact, event, and mover facts; stock loadout; Entity/Jump/gameplay events; and frozen projectile records. The StudioModel phase supplies exact activity timing, posed positions/normals/tangents, attachments, and presentation events for explicit skin/bodygroup/LOD requests. Browser camera mapping uses TF2's default 75-degree horizontal-4:3 world FOV, Source near Z 7, and binary32 map-extent far Z; Rendering owns projection conversion.

`mapDerivedKey` uses compiler contract `playsrc-map-runtime-9`; presentation cache identity uses `playsrc-tf2-presentation-v6`. A cache hit is admitted only after staged compilation reports matching length and SHA-256. Corruption or transfer failure discards the staged handle and preserves the prior generation.

Projectile presentation consumes identity, team, state, quaternion, angular velocity, contact normal, ordered events, exact model attachment transforms, Particle sheets, and Source sound-definition identities. Local first-person rockets do not emit `rocketbackblast`. Multi-wave explosion selection remains blocked until game authority supplies `SoundSamples`. Configured stock first-person items require class hand models plus parented item `c_model` attachments; the current legacy `v_model` pose records do not satisfy that contract and remain explicitly blocked.

`src/presentation.ts` includes viewmodel-bob behavior adapted from Valve Source SDK 2013 and is subject to the Source 1 SDK License in the repository root.
