# TF2 Browser Adapter

The adapter owns the browser worker boundary for the game-owned TF2 WASM module. One worker verifies at most 64 MiB of transferred WASM bytes against their SHA-256, compiles one transferred BSP of at most 512 MiB with at most 64 MiB of exact configuration/dependency bytes, retains one generation-checked gameplay session, returns the canonical map payload as one transferable buffer of at most 64 MiB only on a derived-cache miss, advances 1 through 64 fixed ticks per 24-byte command, and returns one transferable versioned snapshot of at most 64 MiB per phase. The client permits at most 64 pending requests. The application owns immutable-object fetching, pacing, input bindings, routing, IndexedDB lifetime, and worker termination.

`mapDerivedKey` is the lowercase SHA-256 of UTF-8 `playsrc-map-runtime-1\n<BSP SHA-256>\n<lighting profile integer>\n<configuration SHA-256>\n`. A cache hit supplies presentation bytes only after the staged worker compilation reports the same payload length and SHA-256. A cache miss copies the staged payload once, verifies and stores it, then activates the session. Cache corruption, transfer failure, or write failure discards the staged handle and preserves the prior active generation.

`tf2Presentation` maps authoritative projectile positions and supplied Particle render items to Rendering effects. Exact rocket/sticky StudioModel resources are currently unavailable to the browser scene, so ordinary mapping emits `MissingProjectileModel`; an explicit diagnostic mode adds colored spheres without claiming model parity. Fire and explosion events emit exact missing-context diagnostics until weapon/surface mappings and resolved Audio/Particle resources are supplied; no sound or particle substitute is emitted.
