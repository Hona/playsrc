# TF2 GameUI Model

This module owns the immutable TF2 Main Menu, Loading, In Game, single-dashboard Pause, Disconnecting, and Failure state model. Its integration presents the build-selected opaque `background_2fort` standard/widescreen BasePanel image beneath the independently selected character and proportional override, hides it outside the disconnected Main Menu, retains full-viewport bounds across aspect/DPR changes, preserves the configured command catalog, and emits typed requests without browser navigation, matchmaking, store, network, map-loader, Simulation, or product-lifecycle authority.

Validated map commands and owner loading starts remain available in all six states, including loading failure, active gameplay, cancellation, and replacement. The distinct `escape` input opens in-game Pause, emits one pending resume request until `gameui-hidden`, routes loading/error cancellation through owner-confirmed disconnect, and never hides the disconnected Main Menu. Loading progress preserves one modal dialog; failure swaps its configured resource without duplicating the dialog, and completion releases its popup/modal/input ownership exactly once.

Import `./model` for the state, command, transition, menu, and loading contracts. Run `bun test games/tf2/browser/tests/gameui games/tf2/browser/tests/gameui-integration games/tf2/browser/tests/startup-presentation games/tf2/browser/tests/loading-presentation` from the repository root.
