# TF2 WASM Binding

The module compiles one BSP/configuration pair through Map, Material, VTF, StudioModel v3, Particle, Entity, Collision, and Visibility and initializes one generation-bound gameplay session at the first ordered valid `info_player_teamspawn`. One prepared visibility authority, verified resource-hash index, bounded presentation allocation, and shared decoded texture planes preserve exact native/WASM artifact bytes while removing redundant source-sized copies. Handles retain canonical map/presentation bytes, exact decoded model and environment resources, Particle sheets, visibility/collision worlds, gameplay state, bounded phase outputs, and explicit disposal.

`playsrc_compile_map` accepts LDR profile `0` or HDR profile `1`. It returns classified failure for malformed BSP, unknown profile, failed canonical compilation, missing/malformed spawn, failed Entity runtime, incomplete lighting, missing material/profile dependencies, or missing model dependencies. `playsrc_spawn_copy` emits exactly 40 little-endian `PSIV` version-1 bytes containing entity ordinal, Hammer ID or `0xffffffff`, origin, and angles.

Configured `pl_upward` emits PSMP schema 5 with deterministic displacement metadata/geometry, two-axis detail state, distinct UnlitGeneric model evidence, Source entity numeric coercion and the unchanged noclip-enabled Jump session.

PTF2 appends one footer-addressed `PSPA` v1 static-prop section. It retains all 1,244 source-ordered occurrences as references to 234 deduplicated model artifacts; exact transforms, skin/body/root LOD, fades, flags, optional lighting origins and leaf/area ownership; both profile-qualified `PVHA` v2 VHV joins for every vertex-lit occurrence; and four runtime-lit records containing Source's ordered 162-ray surface-light ambient cube plus bounded Collision-occluded world lights with self exclusion. The native decoder validates the complete immutable section. Browser code decodes these records but does not create static-prop GPU resources in this checkpoint.

`playsrc_game_advance` accepts the fixed 84-byte `PCMD` v10 game-input transaction and bounded ticks. The Session owns rigid-body simulation and lifetime; external body-result injection is absent. `PSSN` v33 serializes gameplay, Collision, random/audio, Entity/mover and projectile publications atomically. Header word 96 carries the current launcher's pipebomb count, including linked retiring objects; Stickybomb Launcher loadout scalar 44 carries Rust-computed charge progress. Snapshot length and loadout stride are unchanged, and old snapshot versions are rejected.

`playsrc_model_transact` accepts PMRQ v5 and returns PMPO v4 exact phase, facing, draw eligibility, applied bodygroups, events, timing, posed vertices, tangents, attachments, and opaque/translucent partitions. Stock requests compose separate hand and item `c_model` parts through StudioModel bone merge. PTF2 v12 carries typed alpha ownership/discard, exact PMST v2 state for all 12 selected Particle materials, PSMP v3 facing, source-backed BC/direct model and environment texture planes, decoded channel-converted planes, collision-selected marks, Water/controller state and the bounded static-prop section. `playsrc_visibility_query` emits PVIS v3 with unchanged PVS candidates, separate perspective-frustum world draws, and main/Water auxiliary views. `playsrc_particle_transact` accepts PPTX v2 source timestamps/graceful stops and emits PSPR v3 render records.

`playsrc_jump_configure` is an external-authority seam that atomically installs one 52–65,536-byte `PJMP` version-1 linear course whose map hash equals the session BSP and whose trigger identities resolve in the Entity world. The application does not call it for `jump_beef` because no accepted Tempus core/zone contract maps those contacts. `playsrc_runtime_count` exposes button, door, movelinear, multiple, hurt, push, catapult, teleport, regenerate, and teleport-destination counts for fixed map evidence. Any stale handle, malformed command/course, failed transition, or snapshot overrun preserves the prior live session and snapshot.

The owning TF2 crate also exposes a bounded all-class core. This WASM module does not compose it with the compact direct-map `Session`: no complete command/snapshot/browser replacement contract exists, and retaining one current authority is mandatory. The added generic Entity/contact/angular/path-mover APIs remain available at package seams while this target continues to consume its established compatible linear-mover and Collision snapshot interfaces.
