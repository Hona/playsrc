# TF2 WASM Binding

The module compiles one BSP/configuration pair through Map, Material, VTF, StudioModel v3, Particle, Entity, Collision, and Visibility and initializes one generation-bound gameplay session at the first ordered valid `info_player_teamspawn`. Handles retain canonical map/presentation bytes, exact decoded model and environment resources, Particle sheets, visibility/collision worlds, gameplay state, bounded phase outputs, and explicit disposal.

`playsrc_compile_map` accepts LDR profile `0` or HDR profile `1`. It returns classified failure for malformed BSP, unknown profile, failed canonical compilation, missing/malformed spawn, failed Entity runtime, incomplete lighting, missing material/profile dependencies, or missing model dependencies. `playsrc_spawn_copy` emits exactly 40 little-endian `PSIV` version-1 bytes containing entity ordinal, Hammer ID or `0xffffffff`, origin, and angles.

`playsrc_game_advance` accepts one 48–65,536-byte `PCMD` v4 transaction and 1–64 ticks. It builds immutable Collision v2 snapshots from exact world, active mover, configured `func_brush`, and handled PHY shapes; resolves prior rocket traces; advances concurrent configured linear pushers; applies ordered block/progress/completion/carry results; and accepts only caller-owned sticky-Physics results. `PSSN` v8 serializes those facts plus complete restorable TF2 random streams, typed draws, selected audio events, Movement/Entity/Jump/gameplay/projectile state, producer activities/requests, resupply and locker animation state, IVP/Tempus blockers, and final `PMTK`. The transaction commits atomically.

`playsrc_model_transact` accepts PMRQ v5 and returns PMPO v4 exact phase, facing, draw eligibility, applied bodygroups, events, timing, posed vertices, tangents, attachments, and opaque/translucent partitions. Stock requests compose separate hand and item `c_model` parts through StudioModel bone merge. PTF2 v8 carries typed alpha ownership/discard, PSMP v3 facing, complete model and selected alpha/Water texture chains, collision-selected marks, and Water/controller state. `playsrc_visibility_query` emits PVIS v2 main and Water auxiliary views with view-qualified surfaces. `playsrc_particle_transact` accepts PPTX v2 source timestamps/graceful stops and emits PSPR v3 render records.

`playsrc_jump_configure` is an external-authority seam that atomically installs one 52–65,536-byte `PJMP` version-1 linear course whose map hash equals the session BSP and whose trigger identities resolve in the Entity world. The application does not call it for `jump_beef` because no accepted Tempus core/zone contract maps those contacts. `playsrc_runtime_count` exposes button, door, movelinear, multiple, hurt, push, catapult, teleport, regenerate, and teleport-destination counts for fixed map evidence. Any stale handle, malformed command/course, failed transition, or snapshot overrun preserves the prior live session and snapshot.

The owning TF2 crate also exposes a bounded all-class core. This WASM module does not compose it with the compact direct-map `Session`: no complete command/snapshot/browser replacement contract exists, and retaining one current authority is mandatory. The added generic Entity/contact/angular/path-mover APIs remain available at package seams while this target continues to consume its established compatible linear-mover and Collision snapshot interfaces.
