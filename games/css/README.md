# Counter-Strike: Source

## Objective

Implement Counter-Strike: Source game behavior over generic Source modules after the TF2 target.

## Responsibilities

- Own CS:S players, weapons, economy, teams, movement differences, entities, objectives, rules, replicated state, and presentation mappings.
- Provide the game behavior used by every CS:S ruleset and product.

## Non-Responsibilities

- Generic Source behavior or legacy CS:GO differences.
- Mode behavior owned by a CS:S ruleset.
- TF2-first implementation milestones.

## Relationships

Will compose generic packages and supply game behavior to [`rulesets/`](rulesets/) and CS:S applications.

## Completion

Complete when the future declared CS:S behavior universe is handled with credible evidence.
