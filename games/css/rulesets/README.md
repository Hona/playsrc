# Counter-Strike: Source Rulesets

## Objective

Own mode-specific rules layered over Counter-Strike: Source behavior.

CS:S surf, bhop, KZ, competitive, and standard-mode targets will be defined here by the CS:S roadmap. They do not share implementations merely because another game uses the same mode name.

Rulesets consume CS:S mechanics and do not reimplement generic Source or game-wide behavior.
