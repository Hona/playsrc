# Source Dependency Bundle

The configured `tf2Dir` is `<force-install>/tf`. Build admission reads exactly `<force-install>/steamapps/appmanifest_440.acf`; it never searches parent Steam libraries or substitutes a GUI-library `steamapps/common` layout.

`playsrc-source-bundle <map>` verifies `games/tf2/content-build.json` against the configured TF2 app, build, patch, depot, gameinfo, and selected archive-index identities; admits only `tf/custom/workshop` from the `custom_mod` wildcard; derives the remaining GAME precedence from exact `gameinfo.txt`; and resolves the BSP PAK plus selected VPK, loose, and download providers for world, model, particle, and audio presentation. It includes every requested MDL/VVD/DX90.VTX/ANI/PHY companion or exact optional absence, selected VMT/VTF inputs, five target PCFs, eight stock WAVE resources, `game_sounds_weapons.txt`, and `soundmixers.txt`, then writes one deterministic lowercase-path `PSDB` of unchanged Source bytes.

The playsrc tool builds this generator with the bounded native `source-bundle` Cargo profile and records a cache report bound to the exact generator-executable SHA-256. A warm command reuses PSDB, PUIB, and ledger paths only when the report parses, the executable identity matches, and every artifact has its declared byte length; each consumer recomputes immutable descriptors before publication. A generator change, missing or malformed report, or missing or truncated artifact runs complete generation. Byte-identical generated artifacts are not rewritten.

For `jump_beef`, the build-`24245096` Source closure is 899 entries, 256,997,450 bytes, SHA-256 `616f4b1ebb62e394a2fd1fdd31ca1f01d3de288540ab2c4b8cb596df9265432b`. It includes every found current-build UI source, SFNT/VBF font, VMT, and VTF admitted by descriptor `tf2-ui-24245096-665e7e9c968b7b13` plus 17 generated code-selected HUD images, exact runtime rounded-background, and `stamp_background_map` material/texture inputs. A separate 258-entry `PUIB` is 36,564,904 bytes with SHA-256 `1971de13a4de017fd471217abbd92a4a369a2ee4b733f8145908d04a2652dd10`; it carries deterministic browser PNG adaptations, one material-composition descriptor, and exact configured `startupvids.txt`/`valve.webm` bytes without entering the WASM map-compiler configuration. `valve.bik` is identity-verified but not transferred to the browser.

The same command writes `jump_beef.dependencies.json`: 939 bounded requests comprising 899 resolved entries and 40 optional authoritative absences, plus three startup-source records, in 661,308 bytes with SHA-256 `d627067bad756dbc9631b58813272edc5fb01b369d1cd72fb8165ff7a5753ddc`. Resolved rows and startup records retain exact bytes, SHA-256, provider identity/revision/location, consumer or bundle disposition; the map-photo absence retains all 13 checked GAME locations. The PSDB, PUIB, and ledger descriptors are verified before local Asset Store publication.

Normal generation uses the bounded `source-bundle` Cargo profile, omits the `verify-hdr` dependency closure, reuses already resolved logical paths, converts UI textures through at most eight scoped workers, allocates exact serialized capacities, and compares installed artifacts through a fixed 64 KiB buffer before deterministic path-ordered publication. On the measured Windows host, a clean native build decreased from 48,550 ms to 26,390 ms; generation measured 5,388 ms and exact warm resolution measured 210 ms.

`bun run verify:tf2-wasm jump_beef` internally invokes the bounded `--verify-hdr` evidence mode. That mode writes `jump_beef.native-hdr.psmp` beside the bundle and reports its payload and derived hashes for byte comparison with WASM; it is not a development, publication, or browser prerequisite.

The browser transfers only the PSDB to the Rust WASM compiler that parses VMT/VTF and StudioModel companions and emits the runtime map/model payload. The browser VGUI adapter consumes the separate PUIB; no decoded UI image crosses into map compilation.
