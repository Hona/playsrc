# Source Dependency Bundle

The configured `tf2Dir` is `<force-install>/tf`. Build admission reads exactly `<force-install>/steamapps/appmanifest_440.acf`; it never searches parent Steam libraries or substitutes a GUI-library `steamapps/common` layout.

`playsrc-source-bundle <map>` verifies `games/tf2/content-build.json` against the configured TF2 app, build, patch, depot, gameinfo, and selected archive-index identities; admits only `tf/custom/workshop` from the `custom_mod` wildcard; derives the remaining GAME precedence from exact `gameinfo.txt`; and resolves the BSP PAK plus selected VPK, loose, and download providers for world, model, particle, audio, VGUI, font, startup, and generated browser presentation. It assigns exact lifecycle roles, packs paths by role set and six SHA-256 path-prefix bits, isolates resources at least 4 MiB, applies deterministic raw DEFLATE only at a measured 5% saving, and writes one verified resource root plus immutable encoded chunks.

The configured install shape selects exactly one app-manifest path. A TF2 install beneath a directory named `common` reads `appmanifest_440.acf` from that directory's parent `steamapps`; every other configured install shape reads `steamapps/appmanifest_440.acf` beneath the configured install root. The operation checks only that derived path and reports it on failure; it performs no filesystem search or fallback lookup.

The playsrc tool builds this generator with the bounded native `source-bundle` Cargo profile and records a cache report bound to the exact generator-executable SHA-256. A warm command reuses the graph, chunk, and ledger paths only when the report parses, the executable identity matches, the root verifies, every chunk has its declared byte length, and graph totals agree. A generator change or missing, malformed, or truncated artifact runs complete generation. Byte-identical artifacts are not rewritten.

For `jump_beef`, build `24245096` produces 1,165 logical resources in 144 chunks. Encoded chunks total 118,949,993 bytes; the 254,664-byte canonical root has SHA-256 `0ec0858f928bf4cd501fc87a5486941b043f2bcc9cff1c19f6f05261fe1cc265`. Startup selects 2 entries and 1,323,980 encoded bytes; Main Menu selects 860 entries and 62,171,063 encoded bytes; gameplay selects 305 entries and 56,244,327 encoded bytes. The five resolved chapter-1 `background_2fort` standard/widescreen source objects and generated typed descriptor belong only to Main Menu. `valve.bik` remains identity-verified and is not transferred.

The same command writes `jump_beef.dependencies.json`: 944 bounded requests comprising 904 resolved entries and 40 optional authoritative absences, plus three startup-source records, in 664,374 bytes with SHA-256 `fe01f384c4e31bb8d6480a09abafeffbf29b8449cf1a772532c0e1e80776d2aa`. Resolved rows retain exact byte identity, provider identity/revision/location, and consumers; absences retain every ordered checked location. The ledger names the exact resource root.

Normal generation uses the bounded `source-bundle` Cargo profile, omits the `verify-hdr` dependency closure, reuses already resolved logical paths, converts UI textures through at most eight scoped workers, allocates exact serialized capacities, and compares installed artifacts through a fixed 64 KiB buffer before deterministic path-ordered publication. On the measured Windows host, a clean native build decreased from 48,550 ms to 26,390 ms; generation measured 5,388 ms and exact warm resolution measured 210 ms.

`bun run verify:tf2-wasm jump_beef` internally invokes the bounded `--verify-hdr` evidence mode. That mode writes `jump_beef.native-hdr.psmp` beside the bundle and reports its payload and derived hashes for byte comparison with WASM; it is not a development, publication, or browser prerequisite.

The browser transfers one encoded chunk batch per selected lifecycle role to Rust/WASM. Rust verifies encoded hashes, decodes identity or raw-DEFLATE chunks, verifies decoded and per-entry hashes, and emits one sorted resource set. Only the 305-entry gameplay set enters map compilation; VGUI consumes the independently decoded menu set.
