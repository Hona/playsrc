# Source Dependency Bundle

`playsrc-source-bundle <map>` verifies the configured TF2 app/build/depot identities, derives GAME precedence from the exact `gameinfo.txt`, and resolves the BSP PAK plus configured wildcard, VPK, loose, and download providers for world, model, particle, and audio presentation. It includes every requested MDL/VVD/DX90.VTX/ANI/PHY companion or exact optional absence, selected VMT/VTF inputs, five target PCFs, eight stock WAVE resources, `game_sounds_weapons.txt`, and `soundmixers.txt`, then writes one deterministic lowercase-path `PSDB` of unchanged Source bytes.

The playsrc tool builds this generator with the bounded native `source-bundle` Cargo profile and records a cache report bound to the exact generator-executable SHA-256. A warm command reuses PSDB, PUIB, and ledger paths only when the report parses, the executable identity matches, and every artifact has its declared byte length; each consumer recomputes immutable descriptors before publication. A generator change, missing or malformed report, or missing or truncated artifact runs complete generation. Byte-identical generated artifacts are not rewritten.

For `jump_beef`, the Source closure is 867 entries, 254,281,294 bytes, SHA-256 `c6b02effb40331cb35b1a33c57e1f3f9ad78907421fabdd1e83bd233f7add1ed`. It includes every found build-24207079 UI source, SFNT/VBF font, VMT, and VTF admitted by the checked TF2 UI descriptor plus the exact runtime health and rounded-background materials. A separate 240-entry `PUIB` is 33,036,071 bytes with SHA-256 `5a31b00c87ca0ac2f8cfcce13e7222be2c025a6806f6be426da5afb0b576811d`; it carries deterministic browser PNG adaptations and one exact material-composition descriptor without entering the WASM map-compiler configuration.

The same command writes `jump_beef.dependencies.json`: 906 bounded requests comprising 867 resolved entries and 39 optional authoritative absences, 729,591 bytes, SHA-256 `a6ef1eeee5b3b8557cd85852bcf848a7641d377b1580152a2a7f9e1be9e2fbbd`. Each resolved row records exact app/build/depot identity, bytes, provider revision/location, and consumers. Each absence records every exact checked location. The PSDB, PUIB, and ledger descriptors are verified before local Asset Store publication.

Normal generation uses the bounded `source-bundle` Cargo profile, omits the `verify-hdr` dependency closure, reuses already resolved logical paths, converts UI textures through at most eight scoped workers, allocates exact serialized capacities, and compares installed artifacts through a fixed 64 KiB buffer before deterministic path-ordered publication. On the measured Windows host, a clean native build decreased from 48,550 ms to 26,390 ms; generation measured 5,388 ms and exact warm resolution measured 210 ms.

`bun run verify:tf2-wasm jump_beef` internally invokes the bounded `--verify-hdr` evidence mode. That mode writes `jump_beef.native-hdr.psmp` beside the bundle and reports its payload and derived hashes for byte comparison with WASM; it is not a development, publication, or browser prerequisite.

The browser transfers only the PSDB to the Rust WASM compiler that parses VMT/VTF and StudioModel companions and emits the runtime map/model payload. The browser VGUI adapter consumes the separate PUIB; no decoded UI image crosses into map compilation.
