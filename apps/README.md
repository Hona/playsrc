# Applications

Deployable playsrc programs live here. Applications assemble packages, games, and game-owned rulesets without reimplementing their behavior.

## Organization

| Group | Objective |
|---|---|
| [`web/`](web/) | Browser applications used directly by players and viewers. |
| [`services/`](services/) | Continuously running network applications. |

Applications own product composition, process lifecycle, environment integration, and user-facing interfaces. Reusable Source behavior belongs in packages or games.
