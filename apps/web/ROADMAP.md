# Web Applications Roadmap

[`../../docs/roadmap-contract.md`](../../docs/roadmap-contract.md) defines the normative roadmap schema and denominator review gate. [`../../TERMINOLOGY.md`](../../TERMINOLOGY.md) defines Application, Product, Catalog, Channel, Browser cache, delivery status, evidence, and Complete.

## Completion Denominator

This aggregation roadmap contains exactly 29 behavior rows: 2 Active-child completion rows and 27 cross-child browser-application requirements. The current denominator is exactly 29 items. [`tf2/ROADMAP.md`](tf2/ROADMAP.md) and [`tempus/ROADMAP.md`](tempus/ROADMAP.md) are the Active children. [`css/ROADMAP.md`](css/ROADMAP.md) and [`csgo/ROADMAP.md`](csgo/ROADMAP.md) remain Future and do not enter the Active denominator before their root targets are activated.

Every cross-child row applies independently to both Active children. A cross-child row is Ready only when TF2 and Tempus each satisfy it through their own application integration. This roadmap owns aggregation and cross-child consistency; each child owns its concrete product state, routes, catalog, bindings, and deployment configuration.

## Inputs

- One child-owned application identity, application-build identity, selected deployment environment, and exact application route.
- One immutable application configuration containing `application`, `applicationBuild`, `environment`, `channelUrl`, `channelName`, `assetOrigin`, optional `apiOrigin`, `observabilityRelease`, `observabilityEnvironment`, allowed external origins, Content Security Policy inputs, and every `WebApplicationLimits` value. No field has an implicit environment-variable, hostname, route-query, or development default.
- `WebApplicationLimits` is exactly `maxConcurrentRequests=16`, `maxInFlightBytes=536870912`, `maxCatalogEntries=100000`, `maxWorkers=4`, `maxQueuedWorkerMessages=64`, `maxWorkerMessageBytes=67108864`, `maxUserFileBytes=2147483648`, `maxPersistedSettingsBytes=262144`, `maxUrlBytes=4096`, `maxProgressItems=256`, `maxDiagnostics=256`, `rootLoadTimeoutMs=120000`, `externalRequestTimeoutMs=30000`, and `shutdownTimeoutMs=5000`.
- One exact channel record, immutable application-root descriptor, application-owned catalog, selected game/map roots, and immutable object closure supplied through the current Asset Service and Asset Store interfaces.
- Current coarse interfaces from Simulation or Replay, the selected game and ruleset, Rendering, Particle, Audio, VGUI, Networking when an experience requires it, and browser-facing content consumers. Applications never receive a mutable domain implementation.
- Browser events carrying trusted state, physical code or pointer identity, timestamp, modifiers, focus/visibility revision, and target ownership; browser lifecycle events; one application-owned DOM root; one Rendering canvas; and one VGUI mount root when selected.
- W3C WebGPU Candidate Recommendation Draft 14 July 2026, W3C Pointer Lock 2.0, Web Audio API Recommendation 17 June 2021, DOM AbortController, HTML history/page-transition and storage contracts, and W3C WCAG 2.2 Recommendation 12 December 2024.
- The eight exact browser profiles in the Completion Denominator. Unlisted browsers, operating systems, architectures, and input profiles are outside the current compatibility claim.

## Outputs

- One child-owned product state in exactly `Booting`, `Selecting`, `Loading`, `Ready`, `Suspended`, `Failed`, or `Closed`, with one monotonically increasing operation generation and no stale-generation publication.
- One canonical product route, selected catalog entry, channel-record identity, immutable application-root identity, selected experience identity, and typed child route state.
- One bounded progress tree whose leaves name operation, immutable resource identity, loaded bytes when known, total bytes when known, completed work units, cancellation state, and terminal result.
- One ordered stream of normalized binding events and application commands delivered only to the current game, ruleset, Replay, VGUI, or product-state consumer.
- One user-visible failure containing one `ApplicationFailureCode`, failed operation, affected route or immutable identity, retryability, exact next action, retained prior state, and bounded diagnostic identity. `ApplicationFailureCode` is exactly `ConfigurationInvalid`, `UnsupportedBrowserProfile`, `UnsupportedCapability`, `ChannelUnavailable`, `CatalogInvalid`, `RootUnavailable`, `IntegrityFailure`, `BoundExceeded`, `Cancelled`, `Timeout`, `WorkerFailed`, `InputUnavailable`, `PointerLockDenied`, `AudioUnavailable`, `PermissionDenied`, `GpuRecoveryFailed`, `PersistenceUnavailable`, `RouteInvalid`, `UserFileInvalid`, `ProfileMismatch`, `ExternalDataUnavailable`, `RateLimited`, `DependencyFailed`, `ShutdownFailed`, or `ApplicationFault`. Raw exceptions, stack traces, credentials, machine paths, and unrestricted upstream text are never user-visible.
- One bounded observation stream keyed by application build, environment, route, operation generation, browser profile, root identity, experience, worker, lifecycle state, error code, duration, and byte/work counters.
- One shutdown result proving cancellation, worker termination, pointer-lock release, input neutralization, presentation disposal, transport closure, listener removal, and absence of late publication.

## Invariants

- One top-level document owns one application runtime. One selected Simulation session or Replay session owns authority for the active experience; application, worker, UI, renderer, and storage state cannot replace it.
- Legal product-state edges are exactly `Booting -> Selecting|Failed|Closed`; `Selecting -> Loading|Closed`; `Loading -> Ready|Selecting|Failed|Closed`; `Ready -> Loading|Suspended|Selecting|Failed|Closed`; `Suspended -> Ready|Selecting|Failed|Closed`; and `Failed -> Booting|Selecting|Closed`. `Failed -> Booting` is an explicit full retry; `Failed -> Selecting` is legal only when the immutable application root remains validated. `Closed` is terminal.
- Startup validates complete configuration and the browser profile before requesting a channel, catalog, root, user file, external record, worker, audio context, or GPU device.
- A channel is resolved once per boot. The selected immutable application root and its reachable catalog/root identities cannot change during that runtime. A changed channel is observed only by a new boot or explicit full application update.
- Channel and mutable catalog-metadata responses are never immutable-object truth. Immutable objects are accepted only under their declared descriptor, byte length, media type, and SHA-256 identity.
- Browser HTTP caching may satisfy an exact immutable URL. Channel and mutable product-data requests require current validation. No service worker, Cache API, stale response, extracted tree, alternate origin, or offline bundle is a second asset authority.
- Every asynchronous operation belongs to one generation and one cancellation tree. Navigation, replacement, failure, or close aborts all descendants. Completion from an older generation is inert and releases its resources.
- Workers receive bounded coarse operations and transferable or streamed immutable data. They cannot own DOM, routing, browser permission UI, durable settings, another gameplay loop, another replay timeline, or an application-global singleton after termination.
- Browser events are normalized before domain handoff. The application owns physical bindings and focus safety; games own command meaning, Simulation owns admission/ticks, and Replay owns playback operations.
- Pointer lock is requested only from a user activation on a declared desktop gameplay or free-camera surface. Failure leaves controls neutral and visible. `Escape`, focus loss, route change, suspension, and close release lock and clear held bindings once.
- Hidden, blurred, page-hidden, or restored documents never advance gameplay or replay from elapsed wall time. Suspension stops frame pacing, neutralizes held input, and requests an owner-defined pause. Resumption never reacquires pointer lock or audio permission without a new user activation.
- Audio begins suspended. One explicit user activation requests resume through Audio's browser adapter. Denial, interruption, re-suspension, and closure remain visible states and never select another playback implementation.
- Rendering owns WebGPU device loss and recovery. The application pauses the experience, presents `Recovering`, and resumes only after Rendering returns Ready under the identical profile. Terminal recovery failure returns to product selection or a new explicit retry; no reduced renderer is selected.
- Settings have one current schema and atomic IndexedDB record. Invalid or stale bytes are rejected and replaced only by current defaults after a visible reset result; no migration, legacy reader, or schema branch exists. Settings never contain gameplay, replay, catalog, root, credential, or asset truth.
- Product UI and every app-owned control conform to WCAG 2.2 Level AA, preserve visible keyboard focus, expose deterministic names/roles/states/errors/progress, honor reduced motion, and provide non-drag alternatives. VGUI owns accessibility inside its subtree.
- Every route has one canonical serialization. Back, forward, reload, direct navigation, malformed parameters, and bfcache restoration produce the same selected product state or one exact route failure; URL data never authorizes an unlisted channel, origin, root, or file.
- Every request, byte, catalog entry, worker, worker message, file, URL, progress node, diagnostic, timeout, and shutdown step is charged before allocation or mutation. Limit-plus-one fails without partial publication.

## Ownership Exclusions

- Format parsing, logical-path resolution, map semantics, gameplay, rulesets, Simulation, Networking, Replay, rendering semantics, particles, audio semantics, VGUI semantics, and Asset Store behavior remain with their registered package or game owners.
- Applications supply canvas, DOM roots, browser adapters, physical input bindings, permissions, routes, product state, catalogs, and lifecycle. They do not parse Source bytes, advance domain state, choose game outcomes, decode network/demo payloads, submit GPU work directly, mix audio, or construct generic VGUI controls.
- Asset Store owns object, root, catalog-envelope, channel, retention, and publication truth. Asset Service owns HTTP routing, range, cache headers, and request observability. Applications own catalog entries, labels, order, experience selection, and application-root contents.
- Service applications own proxy, authentication, matchmaking, game-server, and hosted transport endpoints. Infrastructure owns DNS, CDN, storage, compute, secrets, routing, and provisioned observability sinks. Each web child owns only the configuration it requires from those resources.
- Preact owns the product shell DOM it creates. VGUI owns its direct-DOM subtree. Rendering owns its canvas pixels. No reconciler may adopt the VGUI subtree or world canvas.
- CS:S and legacy Source 1 CS:GO remain Future children. Their roadmaps cannot contribute to Active web-application readiness before root activation and accepted game/ruleset denominators.

## Exit Criteria

The Active Web Applications aggregation is Complete only when all of these predicates pass:

- All 29 behavior rows are Ready.
- The denominator review records `Accepted`, reviewer identity, review date, reviewed commit, and a passing result for all eight review predicates.
- Both Active children are Complete under the same eight browser profiles and current shared contract.
- Every profile passes startup, capability, channel/catalog/root, cache, progress, cancellation, error, input, pointer-lock where applicable, focus, audio, GPU-loss, settings, persistence, accessibility, URL, navigation, shutdown, observability, and deployment evidence.
- Every child route and experience selects one immutable application root and one authority path; no route or browser state creates a second game, ruleset, replay, rendering, VGUI, asset, or service authority.
- Every request, byte, catalog entry, worker, message, user file, URL, progress node, diagnostic, and shutdown operation passes its configured bound evidence.
- No required item remains Blocked, Unsupported, Unknown, Missing, Malformed, Partial, stale, duplicated, owner-conflicting, or dependent on a fallback, compatibility layer, or legacy path.

## Blockers

- **Asset HTTP acceptance:** Asset Service declares four exact object/root/catalog/channel route families, but its Draft denominator, backing Asset Store interface, numeric service profile, deployed origin, and consumer integration are not accepted. `WEB-007` through `WEB-010` cannot complete. Checked Asset Service, parent service, Asset Store, Infrastructure, and both Active child roadmaps.
- **Tempus proxy ownership:** the Tempus child requires product-specific API and DEM proxy transport, while the shared API Service explicitly excludes Tempus-specific and single-product endpoints. No separately registered Tempus service exists. The root owner registry and both affected roadmaps must assign the transport before either denominator can be accepted.
- **Presentation/browser interfaces:** Rendering and Audio are Draft and unimplemented. VGUI is registered by the root Owner Registry, but `packages/formats/keyvalues/ROADMAP.md` assigns VGUI construction, layout, scheme, commands, and interaction to web applications while `packages/presentation/vgui/ROADMAP.md` and this roadmap assign them to VGUI. The affected accessibility, lifecycle, integration, and child HUD rows cannot pass single-ownership review. Checked all four roadmaps and their Ownership Exclusions.
- **Deployment environments:** Infrastructure declares only `local`; development, staging, and production are Channel names and do not establish hosted environments. No accepted hosted environment, provider, endpoint/resource binding, or deployment manifest exists for either Active child. Application schemas can be implemented, but deployment and end-to-end evidence cannot complete. Checked `ARCHITECTURE.md`, root roadmap, service roadmaps, and Infrastructure roadmap.
- **Active dependency closure:** TF2, TF2 Jump, Simulation, Replay, Rendering, Particle, Audio, VGUI, Asset Store, and required format/world packages have Draft denominators or blocked rows. The child application assembly and cross-child current-interface rows cannot complete against accepted interfaces. Checked every linked child and dependency roadmap.
