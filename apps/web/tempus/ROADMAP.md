## Completion Denominator

This leaf roadmap contains exactly 18 behavior rows. The application exposes exactly eight Active experiences:

| Experience identity | Canonical route | Product result |
|---|---|---|
| `tempus.activity` | `/activity` | Recent map, course, bonus, and top-record activity. |
| `tempus.maps` | `/maps` and `/maps/<mapId>` | Map discovery, search/filter, tiers, ratings, authors, videos, zone counts, and playsrc asset availability. |
| `tempus.zone-records` | `/maps/<mapId>/<zoneType>/<zoneIndex>` | Soldier and Demoman records for one `map`, `course`, `bonus`, or `trick` zone. |
| `tempus.rankings` | `/rankings/<scope>` | `overall`, `soldier`, or `demoman` ranking. |
| `tempus.player` | `/players/<playerId>` | Public player information, statistics, and rank; no signed-in account state. |
| `tempus.record-replay` | `/records/<recordId>` | One record detail and its exact DEM replay window. |
| `tempus.demo-replay` | `/demos/<demoId>` | One demo detail, its run list, and selected full recorded replay. |
| `tempus.jump-practice` | `/play/<mapId>` | One local TF2 Jump Simulation over the selected playsrc map source and course identity. |

`mapId`, `recordId`, `demoId`, and `playerId` are canonical unsigned decimal integers in `1..=9007199254740991` with no leading zero. `zoneType` is exactly `map`, `course`, `bonus`, or `trick`; `zoneIndex` is `1..=2147483647`. The application redirects no malformed alias and never infers identity from a display name.

The external interface is Tempus public API v0 OpenAPI bytes retrieved 16 July 2026 with SHA-256 `3d7bf3b65d4e74a2ae3b12f5c6b45a1cf003f29b6dc35882cccac12c8eb59d99`. The application consumes exactly 12 GET operations: `/activity`; `/maps/detailedList`; `/maps/id/{mapId}/fullOverview2`; `/maps/id/{mapId}/zones/typeindex/{zoneType}/{zoneIndex}/records/list?limit=50`; `/records/id/{recordId}/overview`; `/demos/id/{demoId}/overview`; `/players/id/{playerId}/info`; `/players/id/{playerId}/stats`; `/players/id/{playerId}/rank`; `/ranks/overall`; `/ranks/class/3`; and `/ranks/class/4`.

The denominator is Not accepted. The OpenAPI contract explicitly omits response schemas for activity, player, and rank operations; TF2 Jump, Replay, service endpoints, presentation interfaces, and the shared web denominator are not accepted; and no review record exists.

## Inputs

- The complete shared configuration, limits, browser profile, channel, application root, catalog, lifecycle, input, settings, persistence, accessibility, observability, and deployment inputs from [`../ROADMAP.md`](../ROADMAP.md).
- One application root whose identity is `application=tempus`, one playsrc catalog containing the eight experiences above, and one exact map source/course identity for every entry declared playable by the catalog. Derived map roots are optional cache descriptors.
- Tempus public API v0 responses for exactly the 12 operations above, each retaining request identity, HTTP status, response headers, receipt time, byte length, response-body SHA-256, and schema-validation result.
- One external-request policy: at most one request starts per 1,000 ms; at most one request is in flight; `429` honors an integer `Retry-After` of at most 60 seconds; one operation makes at most four total attempts; every other non-2xx response terminates that operation; all waits and requests obey shared cancellation and the 30,000 ms attempt timeout.
- One exact map-availability join between immutable Tempus `map_info.id`, its current display name, and a playsrc catalog entry containing a verified map source. Tempus metadata cannot create or alter Source bytes, course definition, derived cache identity, or gameplay rule.
- For record/demo replay: one validated record or demo response, one allowed HTTPS demo URL from the deployment-configured host set, exact downloaded byte length/hash, selected DEM profile, and the current Demo, Networking, TF2 recorded-state decoder, and Replay interfaces. A response is either direct DEM bytes or one ZIP archive containing exactly one regular `.dem` entry. ZIP paths are normalized UTF-8 `/` paths with no absolute, empty, `.`, `..`, control, duplicate, or ASCII-case-colliding component; encryption, nested archives, unsupported flags, inconsistent central/local sizes or CRC-32, and compression methods other than stored or deflate are rejected. Compressed response bytes and decompressed DEM bytes are each bounded by `maxUserFileBytes`; decompressed bytes cannot exceed 100 times compressed bytes.
- For jump practice: one accepted TF2 game and `ruleset.jump` composition, immutable `JumpCourseDefinition`, selected map source, optional derived runtime descriptor, and current Simulation interface.
- One committed `JumpRunResult` from the Jump ruleset for product display. No external response can create, validate, repair, or replace that result.

## Outputs

- One Tempus product state containing selected experience, canonical route IDs, external request generations, validated response identities, selected playsrc catalog/map/course identities, and active Simulation or Replay identity where applicable.
- One ordered map discovery view with exact Tempus map IDs, names, Soldier/Demoman tiers and ratings, zone counts, authors, videos, playsrc availability, search/filter state, and deterministic name order.
- One map/course view containing zone identities and names, `map|course|bonus|trick` type, positive index, class-specific records, placements/ranks, player identity, duration, date, demo identity/window, tier/rating, and current fetch timestamp.
- One activity, overall/class ranking, public player, record, and demo view after each owning response schema is accepted.
- One replay-source result and Replay session for a selected record/demo, or one exact external/download/schema/profile failure with no partial replay state.
- One local Jump practice experience and one read-only product result view over committed Jump events/results. This roadmap emits no Tempus record submission or gameplay decision.

## Invariants

- Dynamic Tempus data is product metadata. It cannot override playsrc map, content-build, course-definition, game, ruleset, Simulation, Replay, or asset truth.
- Every route-bound request belongs to the current route generation. Selecting another map, zone, record, demo, player, ranking, or experience cancels prior work and makes its later response inert.
- API scheduling uses one queue, stable request sequence, the exact 1,000 ms start interval, and bounded retry rules. `Retry-After` never blocks the UI thread or outlives route cancellation.
- Response validation occurs before product publication. Missing, extra where prohibited by the accepted schema, malformed, over-bound, wrong-ID, wrong-zone, wrong-class, or cross-response inconsistent fields fail the complete view update.
- Map discovery preserves Tempus IDs and display names. Client search is ASCII-case-insensitive substring matching; `jumpOnly` is an explicit user filter over names beginning `jump_`, not a ruleset or asset-support predicate; final order is Unicode code-point order of normalized display names then numeric map ID.
- A map is playable only when the exact Tempus ID-to-playsrc catalog join exists and its immutable map/course closure validates. Missing availability disables play/replay presentation for that map and remains distinct from external metadata failure.
- Zone types and indexes are display/navigation identities. Jump owns whether a zone starts, checkpoints, completes, invalidates, resets, or emits a result.
- Record and demo durations/ticks are external metadata until Replay validates the DEM. The application never changes a Replay cursor, fills a missing tick, or derives recorded state from a record duration.
- ZIP handling is only an external Tempus transport adaptation. It emits the sole bounded DEM entry or one atomic archive failure and never parses DEM structure, selects a game/profile, persists extracted bytes, or becomes a general archive interface.
- A local Jump result may be displayed and compared with external records only after Jump commits it. The external comparison cannot mutate validity, elapsed ticks, checkpoint trace, or completion.
- The Active target has no sign-in, Steam authentication, credential, private account, record submission, durable personal history, favorite, notification, or account-inventory behavior. Public player pages are not account state.
- External responses are not persisted as current truth. An in-memory response may be reused only for the identical route for 60 seconds and retains its fetch timestamp; expiry or eviction causes a current request. Network failure never presents an expired response as current.

## Ownership Exclusions

- [`../../../games/tf2/ROADMAP.md`](../../../games/tf2/ROADMAP.md) owns TF2 behavior. [`../../../games/tf2/rulesets/jump/ROADMAP.md`](../../../games/tf2/rulesets/jump/ROADMAP.md) owns Jump course/run behavior and result truth.
- Simulation owns gameplay authority; Demo/Networking/TF2 recorded-state decoding/Replay own recorded-state authority. The Tempus application selects sessions and presents outputs only.
- Map, Content, Asset Store, and Asset Service own canonical runtime descriptors, source/derived object identity, graph validity, storage, channels, and HTTP byte/range delivery. Tempus metadata owns no reusable map fact.
- Rendering, Particle, Audio, and VGUI own presentation behavior/resources. This application owns Tempus product shell, routes, selectors, settings, permission UI, and lifecycle.
- This application owns the selected external API contract, request scheduling policy, map/course/record/rank/player product state, and user-visible external failures. A registered service application must own any deployed proxy transport, allowlist enforcement, credentials binding, range forwarding, cache headers, and endpoint observability; no current registered service accepts the Tempus-specific transport.
- Tempus server operation, record validation/submission, rankings calculation, ratings, tiers, demo creation/retention, map authoring/publication, Steam authentication, and account policy are external or undeclared behavior and are not implemented by playsrc.

## Exit Criteria

The Tempus web application is Complete only when all of these predicates pass:

- All 18 behavior rows are Ready and the denominator review is Accepted.
- All eight experiences and canonical routes pass direct-load, history, reload, malformed-input, cancellation, accessibility, and shutdown evidence on all eight shared browser profiles.
- Reviewed schemas cover every consumed field and error for all 12 external operations; every fixed response validates or produces its exact declared failure.
- Every Tempus map selected for play or replay joins to exactly one verified playsrc map source/course identity; external data never overrides source, derived-cache, or gameplay truth.
- Record/demo replay uses one current Demo/Networking/TF2-decoder/Replay authority and makes zero Simulation calls.
- Jump practice uses one current TF2/Jump/Simulation authority; product records, rankings, tiers, ratings, authors, videos, and responses cannot change its state or result.
- External request rate, retry, timeout, response-size, download-size, memory, queue, progress, and cancellation bounds pass fixed evidence.
- No sign-in, credential, private account, record submission, durable personal-history, external server behavior, duplicate authority, fallback, compatibility layer, legacy route, or stale response remains.
- No required item remains Blocked, Unsupported, Unknown, Missing, Malformed, Partial, stale, duplicated, or owner-conflicting.

Checked the exact OpenAPI bytes/hash, public API documentation, and every selected operation.
- **External proxy/download owner:** the shared API Service explicitly excludes Tempus-specific and single-product endpoints, while this application cannot own a deployed network service. No separately registered Tempus service accepts the 12 API operations or DEM proxy transport. Therefore no deployed host allowlist, redirect/range policy, cancellation, response bound, cache behavior, or endpoint observability contract exists. Checked the API and parent service roadmaps, root Owner Registry, this roadmap, and Infrastructure.
- **Jump composition:** TF2, the TF2 ruleset universe, Jump, Simulation, and required map/entity/movement/physics interfaces are Not accepted. Jump's target course semantics and result interface contain blocked items, preventing practice and committed-result integration. Checked each named roadmap and inventory.
- **Recorded-state stack:** Demo, Networking, Replay, and TF2 recorded-state interpretation are Not accepted and expose no complete current interface. Record/demo replay and presentation evidence cannot execute. Checked all four owner roadmaps and current trees.
- **Presentation and shared web dependencies:** Rendering, Particle, Audio, VGUI, Asset Store, Asset Service, shared web requirements, and Infrastructure are Draft or blocked. The Tempus child cannot complete browser, accessibility, root-loading, presentation, deployment, or shutdown integration. Checked all linked roadmaps and the root Owner Registry.
