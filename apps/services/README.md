# Service Applications

## Objective

Run network-facing applications required by playsrc products and future online multiplayer.

## Responsibilities

- Own process lifecycle, transport adapters, authentication, operational configuration, and deployed endpoints.
- Assemble reusable packages and game modules without reimplementing them.

## Non-Responsibilities

- Owning generic Source behavior, gameplay implementations, or infrastructure provisioning.

Each child is one independently deployed service application.
