# Matchmaking Service

## Objective

Match players into compatible future online multiplayer sessions.

## Responsibilities

- Own queues, party requirements, session assignment, admission, and matchmaking lifecycle.
- Coordinate with hosted gameplay servers through explicit interfaces.

## Non-Responsibilities

- Advancing gameplay, defining game rules, or implementing network replication.
- Provisioning server infrastructure.

## Completion

Complete when the future declared matchmaking behavior is bounded, observable, and integrated without becoming gameplay authority.
