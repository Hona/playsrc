# Networking Roadmap

[`../../../TERMINOLOGY.md`](../../../TERMINOLOGY.md) defines delivery statuses, coverage classifications, bounds, backpressure, current contract, and Complete. [`../../../docs/roadmap-contract.md`](../../../docs/roadmap-contract.md) defines denominator, inventory, and evidence requirements.

## Completion Denominator

The current completion denominator contains exactly the 47 Behavior Families rows below. [`inventories/message-and-state-families.md`](inventories/message-and-state-families.md) contains 92 candidate package-owned connection, message, replication, event, and delivery items and 0 accepted items. Candidate items do not enter the denominator until one checked-in generator emits the inventory and a denominator review accepts it. Acceptance of all current candidates would make the denominator 139 items.

The current target is the TF2 network-protocol-24 profile declared by Valve Source SDK 2013 commit `88fa198fba3fb85d46d4c95018254693fdc3af0a`, consumed through one transport-neutral playsrc interface for live sessions and recorded packet payloads. Counter-Strike: Source and legacy Source 1 Counter-Strike: Global Offensive profiles enter this roadmap only when their root targets are activated with exact protocol authorities; the current interface never guesses or falls back to another profile.

The denominator is Not accepted. The candidate inventory has no generator or review record, TF2 has no accepted game-owned replication inventory, and timeout, message-size, rate, queue, history, and memory bounds have not been selected.

## Inputs

- One explicit protocol profile identity, one immutable game-owned schema registry, and one numeric limits value. The registry identifies every replicated class, field, property type, quantization declaration, recipient policy, string table, event, user message, entity message, prediction field, and interpolation field consumed in the session.
- An ordered stream of complete inbound transport payloads with receive time, transport identity, end-of-payload boundary, and cancellation or close signal; and one outbound transport sink that either accepts a complete payload or returns a typed capacity, closure, or I/O result.
- Canonical simulation-owned commands, authoritative snapshots, events, and tick interval; game-owned field accessors and prediction comparison policies; and replay-owned ordering context for recorded payloads.
- Valve Source SDK 2013 commit `88fa198fba3fb85d46d4c95018254693fdc3af0a`: `src/game/shared/usercmd.{h,cpp}`; `src/public/dt_common.h`, `dt_send.h`, `dt_recv.h`, `networkvar.h`, `networkstringtabledefs.h`, `igameevents.h`, `inetmessage.h`, `inetmsghandler.h`, `inetchannel.h`, `inetchannelinfo.h`, and `iclientnetworkable.h`; `src/common/proto_version.h`; `src/game/client/prediction.{h,cpp}`; and the TF2 client, server, and shared networking declarations selected by the game-owned inventory.
- Fixed live and DEM packet captures with protocol identity, content build, source hash, packet boundaries, command inputs, authoritative tick outputs, and required comparison metadata.

## Outputs

- One connection state containing stage, session identity, protocol profile, challenge/admission result, local and remote packet cursors, reliable-delivery state, command cursors, server tick, accepted snapshot tick, baseline identities, queue state, rate state, timeout state, and close reason.
- Ordered decoded messages, admitted command batches, acknowledgement advances, data-table and string-table changes, replicated entity operations, game events, interpolation samples, prediction-history changes, and authoritative correction requests.
- Complete outbound payloads plus delivery class, packet sequence, acknowledgement, reliable-fragment identity, rate eligibility time, and transport disposition.
- Deterministic `Malformed`, `Unknown`, `Unsupported`, protocol-mismatch, denial, timeout, capacity, cancellation, closure, and transport-I/O results. A failed payload publishes no partial authoritative state.
- An observation stream keyed by connection, direction, packet sequence, message identity, command range, server tick, snapshot base, delivery class, queue disposition, byte count, and error code without exposing authentication material or sensitive game-owned values.

## Invariants

- Networking never advances gameplay. Simulation remains the only gameplay authority; replay remains the only recorded-state authority. Networking transports, decodes, applies, compares, and requests resimulation through those owners.
- One session selects one exact protocol profile and one exact schema registry before profile-dependent decoding. A mismatched, absent, or changed identity terminates synchronization without fallback, compatibility parsing, or profile inference.
- Packet, command, tick, fragment, snapshot, baseline, entity, table, and event identities use declared serial arithmetic. Comparison never uses ordinary signed ordering across a wrap boundary.
- A payload is validated against every applicable bit, byte, item, allocation, queue, history, and decompressed-size bound before state publication. Arithmetic is widened and checked before slicing or allocation.
- Reliable messages are delivered once in message order after complete reassembly. Unreliable messages may be omitted as complete messages but are never partially applied. Duplicate or stale packets never repeat state transitions.
- A full snapshot is self-contained under its selected class baseline. A delta snapshot names one retained base. Missing, stale, rejected, or mismatched bases request full state and cannot mutate the current snapshot.
- Entity creation, recreation, field update, preservation, relevance departure, and deletion are distinct ordered operations. One snapshot commits all of its table and entity operations atomically.
- Networking owns scalar and container encoding from schema declarations. Games own field identity, semantic meaning, recipient policy, prediction policy, and interpolation policy.
- Reliable fragmentation and protocol compression occur above the transport seam. A transport adapter may packetize its own carrier but cannot reinterpret networking message boundaries, delivery class, compression identity, or acknowledgement state.
- Prediction retains canonical commands and game-selected predicted fields only within the accepted history bounds. Reconciliation restores an authoritative base and asks Simulation to replay unacknowledged commands; Networking contains no alternate movement, weapon, entity, or ruleset implementation.
- Connection close, denial, timeout, cancellation, level change, and reset release fragment buffers, queued payloads, baselines, schema state, string tables, prediction history, and transport references atomically.

## Ownership Exclusions

- `packages/runtime/simulation` owns command admission into gameplay ticks, deterministic advancement, authoritative event production, and canonical snapshots. Networking owns remote command envelopes, delivery cursors, replicated snapshot encoding, and correction orchestration.
- `games/tf2`, `games/css`, and `games/csgo` own their replicated classes and fields, recipient policies, prediction fields and tolerances, interpolation policies, game event schemas, user-message schemas, entity-message schemas, and game-specific command meaning.
- `packages/runtime/replay` owns recorded-state progression, seeking, playback state, and DEM-order application. `packages/formats/demo` owns only the DEM container and outer record extents; Networking owns the packet, data-table, string-table, and network-message payload codecs handed off by Demo.
- `apps/web/*` and `apps/services/game-servers` own concrete WebSocket, WebTransport, WebRTC, UDP, TCP, process, authentication, reconnect-UI, and browser lifecycle adapters. Networking owns the transport-neutral payload and state contracts those adapters satisfy.
- `apps/services/matchmaking` owns player/session matching, credentials, join policy, and allocation selection. Networking reports an admission result but does not decide who may join.
- `packages/presentation/audio`, `packages/presentation/particle`, and `packages/presentation/rendering` own voice, sound, particle, decal, camera, and visual effects after Networking validates and hands off their declared payloads.
- `packages/content` owns logical-path resolution and resource bytes. Networking owns file-control and reliable-byte envelopes only; it never authorizes paths, discovers files, or selects content providers.
- Infrastructure owns provisioned network resources, routing, firewalls, and observability sinks. Networking emits measurements and never provisions or configures a carrier.

## Exit Criteria

Networking is Complete only when all of these predicates pass:

- All 47 Behavior Families rows are Ready.
- The generated package inventory is current, contains exactly the accepted item set, and has an Accepted review record with reviewer identity, date, reviewed commit, and all denominator-gate predicates passing.
- TF2 supplies accepted generated inventories for every game-owned replicated field, string table, game event, user message, entity message, prediction field, interpolation field, and recipient rule consumed by the current protocol profile.
- Every accepted codec passes whole-buffer, arbitrarily chunked, live-payload, and DEM-payload comparisons with identical values, classifications, bit extents, and errors.
- Deterministic loss, duplication, reordering, wrap, fragmentation, compression, timeout, cancellation, rate, queue, and backpressure schedules pass on native and browser runtimes under the same limits.
- Authoritative correction evidence proves one Simulation implementation advances gameplay for server authority and client resimulation; Networking and presentation never advance gameplay.
- Simulation, Replay, TF2, Demo, web, game-server, and transport-adapter producers and consumers use the current interface; no duplicate network codec, fallback, compatibility layer, legacy path, or stale generated inventory remains.
- No required profile, item, owner, input, dependency, decision, evidence method, value, or behavior remains Unsupported, Unknown, Missing, Partial, or Blocked.

- **Numeric execution contract:** exact browser and native maxima for timeout thresholds, payloads, decompression, schema size, fragment state, rates, bursts, all queues, histories, and aggregate in-flight memory are undecided. Checked SDK `inetchannel.h`, `inetchannelinfo.h`, `dt_common.h`, `networkstringtabledefs.h`, `igameevents.h`, and `proto_version.h`; the declared field widths and interface constants do not establish playsrc execution budgets.
- **Inventory generator:** no checked-in command emits [`inventories/message-and-state-families.md`](inventories/message-and-state-families.md). Checked `tools/`, root package manifests, and the current Networking package tree.
- **Retained target captures:** no retained public capture records a complete protocol-24 TF2 sign-on, command/ack exchange, full snapshot, delta snapshot, rolling-baseline update, string-table update, game-event list, game event, fragmented reliable payload, compressed payload, denial, timeout, and level change for one declared content build. - **Adjacent denominators:** Simulation, Replay, TF2, TF2 web, and game-server roadmaps required for final integration do not exist. This does not prevent package implementation, but it prevents the final integration row and exit criteria from becoming Ready.
