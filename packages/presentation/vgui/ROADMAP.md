# VGUI Roadmap

[`../../../docs/roadmap-contract.md`](../../../docs/roadmap-contract.md) defines the normative roadmap schema and denominator review gate. [`../../../TERMINOLOGY.md`](../../../TERMINOLOGY.md) defines delivery status, coverage classification, inventory, and completion terms.

## Completion Denominator

This leaf roadmap contains exactly 41 behavior rows. The five manually derived Candidate inventories contain 300 items and contribute 0 items until one checked-in generator emits each inventory and a denominator review accepts this roadmap. The current completion denominator is therefore 41 behavior rows. Acceptance of all current candidates would make the denominator 341 items.

The target is generic Source 1 VGUI behavior presented as framework-independent TypeScript through direct browser DOM and CSS. The application shell uses Preact, Vite, and Bun; Preact neither renders nor reconciles VGUI-owned DOM. The root Owner Registry assigns this behavior to `packages/presentation/vgui`, KeyValues owns syntax and composition only, games own game-specific mappings and effects, and applications own browser/product integration. The denominator is Not accepted because required format owners and TF2 inventories are unavailable, generators and package-wide numeric limits are Missing, retained browser evidence is absent, and no review record exists.

Ownership is resolved. Individual rows remain `Not started` or `Blocked` according to their next executable action and external dependencies.

## Outputs

- One VGUI runtime containing stable panel identities, parent and ordered child state, signed z-order, popup order, local and effective visibility, enabled and input-interest state, local and absolute bounds, insets, clipping, layout invalidation, scheme identity, control state, focus, capture, modal state, tick registrations, queued messages, and animation queues.
- One VGUI-owned DOM subtree whose node order, CSS bounds, clipping, opacity, visibility, pointer eligibility, text, images, borders, focus state, accessibility state, and cleanup agree with the runtime state after each committed frame.
- Typed resource-application, scheme, localization, text-measurement, animation, input, focus, command, action-signal, system-request, and diagnostic results. A failed operation publishes no partial subtree or registry.
- One developer-console presentation service accepting immutable catalog snapshots and bounded output batches and emitting typed submission, completion, completion-cancellation, and visibility requests. It never tokenizes for execution, executes a command, mutates a convar, or loads a map.
- Ordered typed requests for application navigation, clipboard, user configuration, cursor lock, audio, and game commands. The receiving owner decides policy and effect.
- An observation stream keyed by runtime, panel, resource, scheme, sequence, command, input context, frame, queue position, viewport revision, and error code without exposing mutable DOM as presentation truth.

## Invariants

- VGUI is one deep module. Applications mount, update, observe, and destroy it through one interface; controls do not expose browser listeners, CSS implementation, parser details, or mutable DOM as caller responsibilities.
- One live panel has one stable identity, at most one parent, one owned DOM node, and no hierarchy cycle. Reparenting removes the old edge before publishing the new edge.
- Sibling paint and hit-test order is signed z-order followed by stable tie order. Painting visits back to front; hit testing visits front to back. Popup order is separate from ordinary child order.
- Effective visibility requires local visibility from the panel through every ancestor. Invisible subtrees do not lay out from frame input, paint, receive input, remain focused, or retain capture.
- Enabled, mouse-input-enabled, and keyboard-input-enabled are independent. Disabled controls retain layout and paint state but expose disabled interaction and accessibility state.
- Source layout units are integer CSS pixels. Proportional conversion scales from 640×480 by viewport height and truncates toward zero. Device-pixel ratio changes raster selection and never changes CSS-pixel panel geometry by itself.
- Layout applies resource values, scheme values, parent geometry, anchors, sibling pins, and control-specific layout in the declared order. One resize or resource commit produces one downstream invalidation closure before paint.
- Non-popup clipping is the intersection of panel bounds and ancestor clips after insets. Popups escape parent clipping but remain clipped to the explicit VGUI workspace.
- Paint order is early border when declared, background, foreground, children, late border otherwise, then post-child foreground. Ancestor alpha multiplies each descendant's own alpha.
- Resource replacement validates the complete typed document, dependencies, factories, references, conditions, and limits before atomically replacing the resource-owned subtree. Missing or unknown items never create substitute controls.
- Schemes, localization tables, font registries, border registries, image registries, and animation script sets are immutable between atomic replacement commits. Controls hold stable handles that are invalidated on replacement or destroy.
- A leading `#` requests localization lookup. Dialog-variable substitution uses only caller-supplied typed values. Missing tokens and variables remain distinct `Missing` results and cannot silently become empty text.
- Animation advances only from the injected clock. Delayed commands use due time then script order. A sequence can mutate registered presentation variables and emit typed requests; it cannot call gameplay, replay, networking, audio, routing, or storage implementations directly.
- Input edge states last for exactly one VGUI frame. Mouse-over, mouse focus, mouse capture, calculated key focus, committed key focus, application modal surface, and modal subtree are distinct states.
- Focus loss is delivered before focus gain. Capture, focus, queued messages, tick signals, listeners, observers, timers, accessibility relationships, font references, image references, and DOM nodes are cleared when their owner is destroyed.
- Browser accessibility and reduced-motion modes are explicit inputs. Reduced motion changes visual interpolation sampling only; command delays, event order, state changes, and sequence completion time remain unchanged.
- Every count, offset, duration, scalar, allocation, lookup chain, traversal, queue insertion, DOM creation, texture upload, and emitted diagnostic is checked against integer range and the supplied limits before mutation.
- Developer-console parsing is limited to finding the first ASCII space for completion routing and history display. Submitted text remains opaque and exact; command owners alone tokenize, validate, execute, mutate convars, acquire content, replace maps, or admit Simulation commands.

## Ownership Exclusions

- `packages/formats/keyvalues` owns lossless KV1 syntax, directives, conditions, composition records, and diagnostics. VGUI owns control-resource and scheme semantics over parsed documents.
- The proposed localization, UI-script, and font format packages own localization-file, HUD-animation-text, and font-file parsing. `packages/formats/vtf` owns VTF bytes. VGUI owns lookup, binding, scheduling, measurement, and browser presentation over typed inputs.
- `packages/content` owns exact logical-path resolution, provider precedence, bytes, provenance, and caching. VGUI requests exact identities and never searches providers or the filesystem.
- `games/tf2` owns health, ammo, weapon selection, objectives, death notices, scoreboards, class and team menus, buildings, conditions, event bindings, game commands, custom control semantics, and immutable HUD presentation mappings. VGUI owns generic controls and their presentation runtime.
- `apps/web/*` own Preact shell composition, routes, navigation policy, uploads, settings policy, browser lifecycle, physical Backquote binding while the console is closed, focus and pointer-lock policy, external-origin policy, persistence adapters, mount roots, typed command/convar/map adapters, and product UI that is not Source VGUI behavior.
- `packages/presentation/rendering` owns world and model pixels, Three.js, GPU resources, and camera presentation. Particle and Audio own their presentation; VGUI emits typed image, particle, and sound requests at those seams.
- Simulation and Replay remain the only gameplay and replay authorities. VGUI cannot mutate either authority, derive missing state, or execute a game command.
- Drag and drop is excluded from the current denominator because no accepted TF2 or shared economy consumer uses the generic panel drag/drop contract. Application file-drop behavior remains application-owned.

## Exit Criteria

VGUI is Complete only when all of these predicates pass:

- All 41 behavior rows are Ready.
- All five inventories are generated, current, Accepted, contain exactly the reviewed 300-item set unless the same checkpoint changes the denominator, and record every metadata and review field required by the roadmap contract.
- The root Owner Registry, KeyValues roadmap, format-universe roadmap, TF2 roadmap, application roadmaps, and this roadmap continue to assign every generic resource, control, HUD, and product behavior to one owner.
- Every accepted TF2 `.res`, scheme, localization, font, border, image, texture reference, HUD-animation manifest, script, sequence, command occurrence, and custom control identity has one handled result or exact required error under one owner.
- Synthetic vectors, fixed target captures, virtual-clock traces, DOM snapshots, accessibility snapshots, browser screenshots, malformed-input records, limit measurements, and cleanup instrumentation satisfy every declared comparison predicate.
- The current Preact applications mount the framework-independent package; every game HUD binding consumes immutable presentation state and emits typed commands; direct Three.js world rendering stays outside VGUI and Preact.
- Every required producer and consumer uses the current interface; no duplicate VGUI resource loader, control factory, animation runtime, input router, DOM owner, fallback, compatibility layer, legacy path, or stale generated artifact remains.
- No required item remains Blocked, Unsupported, Unknown, Missing, or Partial.
